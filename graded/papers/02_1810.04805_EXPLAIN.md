# 1810.04805 BERT — Graded explanations

Source: https://arxiv.org/abs/1810.04805  
Figures: `graded/figures/1810.04805/`

BERT is the second arXiv paper in this corpus. GPT-1 is not on arXiv; BERT uses it as the **left-to-right fine-tuning** baseline. BERT’s claim: pre-train a **deep bidirectional** Transformer encoder with Masked LM + Next Sentence Prediction, then fine-tune one extra layer per task.

Published GLUE/SQuAD/SWAG numbers are plotted from the paper. Local probes check MLM 80/10/10, NSP 50/50, embedding sum, and causal vs bidirectional future mass.

## Figure 1 — pre-train and fine-tune (procedural)

Same encoder for all tasks. `[CLS]` pooled state C for classification; token states T_i for spans/tags. Fine-tune **all** weights. This is why tiny labeled sets (MRPC 3.5k) still move when the encoder is large (Table 6).

## Figure 2 — input representation

`fig2_input_embeddings.png`

E = token + segment + position embeddings. Segment ids distinguish sentence A vs B inside one sequence (`[SEP]` between them). Endpoint `input_sum_err` must be 0.

**Production:** any pair task (NLI, QA, paraphrase) is just this packing plus a head on C or on T_i. No separate cross-attention module.

## §3.1 Masked LM

`fig_mlm_recipe.png`

Choose 15% of WordPieces. Of those: 80% `[MASK]`, 10% random token, 10% leave unchanged. Predict **only** those positions.

Why not 100% `[MASK]`: `[MASK]` never appears at fine-tune time. Why not reconstruct all tokens (DAE): they only train the cloze positions.

Endpoints: `mlm_frac_chosen` ≈ 0.15, `mlm_frac_mask_among_chosen` ≈ 0.80, `mlm_frac_keep_among_chosen` ≈ 0.10.

BERT_BASE = L=12, H=768, A=12, 110M (matched to GPT size). BERT_LARGE = L=24, H=1024, A=16, 340M. FFN inner size = 4H.

## §3.1 NSP

50% IsNext, 50% NotNext, classified from C. Paper: 97–98% NSP accuracy. Helps QNLI/MNLI/SQuAD (Table 5). Endpoint `nsp_mean_label` ≈ 0.5.

Data: BooksCorpus 800M + Wikipedia 2500M **document-level** (not shuffled Billion Word).

## Table 1 GLUE

`fig_table1_glue.png`, `fig_table1_glue_tasks.png`

BERT-large average 82.1 (excl. WNLI); official leaderboard 80.5 vs GPT 72.8. Fine-tune: batch 32, 3 epochs, LR ∈ {5e-5, 4e-5, 3e-5, 2e-5}. LARGE is unstable on small sets → random restarts.

Per-task metrics: accuracy except QQP/MRPC F1, STS-B Spearman.

Endpoints: `paper_glue_base=79.6`, `paper_glue_large=82.1`.

## Tables 2–3 SQuAD

`fig_table2_3_squad.png`

Span scoring: start logit S·T_i, end E·T_j, max j≥i. v2.0: null span is S·C+E·C vs best span + threshold τ.

BERT-large ens+TriviaQA test F1 93.2 (v1.1); v2.0 test F1 83.1. Endpoints store those literature targets.

## Table 4 SWAG

`fig_table4_swag.png`

Four packed (context, ending) sequences; score = vector · C; softmax over 4. BERT-large test 86.3 vs GPT 78.0 vs human-expert 85.0.

## Table 5 pre-training ablation (the BERT vs GPT experiment)

`fig_table5_pretrain_ablation.png`

Same data/hparams as BERT-base:

| | MNLI-m | QNLI | MRPC | SST-2 | SQuAD F1 |
|---|---|---|---|---|---|
| BERT-base | 84.4 | 88.4 | 86.7 | 92.7 | 88.5 |
| No NSP | 83.9 | 84.9 | 86.5 | 92.6 | 87.9 |
| LTR & No NSP | 82.1 | 84.3 | 77.5 | 92.1 | 77.8 |

LTR (GPT-style) collapses span tasks. Adding a BiLSTM on top recovers some SQuAD (84.9) but not BERT. Endpoint `squad_f1_drop_ltr` = 10.7.

Local probe `BidirectionalVsCausal`: causal future mass ≈ 0; bidirectional future mass > 0.

## Table 6 size

`fig_table6_size.png`

MLM PPL falls 5.84 → 3.23 as models grow; MNLI-m 77.9 → 86.6 **including MRPC (3.6k labels)**. Claim: after enough pre-training, size helps even tiny tasks if you fine-tune rather than freeze features. Endpoint `size_ppl_monotonic`.

## Table 7 NER feature-based vs fine-tune

`fig_table7_ner.png`

Concat last 4 layers into a BiLSTM ≈ fine-tuning (96.1 Dev F1 vs 96.4/96.6). Use case: when you cannot backprop the encoder or need a custom head.

## What a “real-world” model must not fail (from this paper)

- Bidirectional context for token-level work (QA, NER).
- Packed pair representation instead of a one-off cross-attn architecture per task.
- Pre-train objective ablation, not just “more data.”
- Size + fine-tune on small data, with restarts if unstable.
- Document-level corpus if you care about sentence relations.
