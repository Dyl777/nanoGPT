# 1706.03762 Attention Is All You Need — Graded explanations

Source: https://arxiv.org/abs/1706.03762  
Figures: `graded/figures/1706.03762/`

This is the first LLM-lineage paper on arXiv: a seq2seq model with **no recurrence and no convolution**, only attention. Every later decoder-only GPT is this architecture with the encoder and encoder–decoder attention removed, plus a causal mask.

**What we do not re-train:** WMT14 4.5M/36M sentence pairs, 8×P100 for 12h–3.5 days. Published BLEU/PPL/F1 are plotted exactly. Local probes test the identities the paper used to *justify* those designs.

## Fig / §3.5 Sinusoidal positional encoding

`fig_positional_encoding.png`

Because there is no RNN, order is injected by adding

PE(pos, 2i) = sin(pos / 10000^{2i/d_model})  
PE(pos, 2i+1) = cos(pos / 10000^{2i/d_model})

**Why it matters in production:** the model must know token order; sinusoids also make PE_{pos+k} a linear function of PE_pos (rotation of each 2D pair), which is the paper’s relative-position argument. The Graded endpoint `pe_relative_mse` is that reconstruction error. Table 3 row (E) found learned embeddings ≈ sinusoids on BLEU; sinusoids were kept for length extrapolation.

## Equation (1) and Figure 2 — scaled dot-product / multi-head

`fig2_scaling_softmax.png`

Attention(Q,K,V) = softmax(QK^T / √d_k) V.

Unscaled dots have variance d_k, so softmax peaks and gradients die. The plot shows mean max attention mass vs d_k with and without scaling.

Multi-head: h=8, d_k=d_v=64, concat then W^O. Cost ≈ one full-dimension head. Endpoints: `causal_mask_ok` (decoder future mass ≈ 0), `multihead_concat_ok` (h·d_v = d_model), `softmax_row_err` (rows sum to 1).

Three uses in the paper: encoder self-attn (full), decoder self-attn (causal), encoder–decoder attn (Q from decoder, K/V from encoder). nanoGPT is the causal self-attn slice.

## Table 1 — complexity

`fig_table1_complexity.png`

Self-attention: O(n²d) compute, O(1) sequential ops, O(1) path length. Recurrent: O(n d²), O(n) sequential, O(n) path. Convolution: O(k n d²), O(1) sequential, O(log_k n) path.

**Production reading:** for sentence n ≪ d, attention is cheaper *and* better at long range. For long context, n² hurts — later papers add restricted / linear / sliding-window attention (the paper already flags restricted radius r).

Endpoint `self_attn_cheaper_n_lt_d` checks n=256, d=512.

## Equation (3) — learning rate

`fig_eq3_lr_schedule.png`

lrate = d_model^{-0.5} · min(step^{-0.5}, step · warmup^{-1.5}), warmup=4000.

Peak should sit at step 4000. Endpoint `lr_peak_step`.

Adam: β1=0.9, β2=0.98, ε=10^{-9} (not the default β2=0.999).

## Table 2 — WMT BLEU vs FLOPs

`fig_table2_bleu.png`, `fig_table2_flops.png`

Published: Transformer base 27.3 / 38.1 BLEU (EN-DE / EN-FR), big 28.4 / 41.8. Base train cost 3.3×10^18 FLOPs vs 10^19–10^21 for prior SOTA.

Inference recipe they used: average last 5 (base) or 20 (big) checkpoints; beam 4; length penalty α=0.6; max decode = input+50.

Endpoints store the big-model BLEU numbers as literature targets, not as a claim that this repo hit them.

## Table 3 — ablations (the actual architecture search)

`fig_table3_heads.png`, `fig_table3_depth.png`, `fig_table3_dropout.png`

- (A) heads: 1 head is −0.9 BLEU; 8 and 16 tie at 25.8; 32 heads drop. Too few *or* too many heads hurt.
- (B) small d_k hurts — compatibility is not a trivial dot.

- (D) dropout 0 → 24.6 BLEU; 0.1 is best; 0.2 slightly worse. Label smoothing 0.0 vs 0.1: PPL better without smoothing, BLEU better with.
- (E) learned PE ≈ sinusoids.

## §5.4 label smoothing

Endpoint `label_smoothing_entropy_gap`: smoothed targets (ε=0.1) have higher entropy than one-hot. That is why PPL gets worse while token accuracy/BLEU can get better.
